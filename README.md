# Система учета товаров — учебный ETL-проект

Рабочий прототип для лабораторной №3 и практической №3. Он читает Excel и CSV, проверяет данные, загружает текущий снимок в SQLite и формирует четыре выборки. Данные полностью синтетические; названия поставщиков, адреса и телефоны вымышлены.

Сначала запускаем проект на вашем компьютере и сохраняем скриншоты. Два отчета оформляем после проверки фактических результатов.

## 1. Что находится в архиве

| Файл | Назначение |
|---|---|
| `etl.py` | Извлечение, очистка, проверка и загрузка данных |
| `schema.sql` | Три таблицы БД и три представления для выборок |
| `show_results.py` | Просмотр результатов из БД в терминале |
| `test_etl.py` | Восемь автоматических проверок |
| `requirements.txt` | Версии двух зависимостей |
| `data/catalog.xlsx` | Листы `products` и `suppliers` |
| `data/inventory.csv` | Остатки и места хранения |

Папка `results` создается при запуске. В архиве нет заранее заполненной базы: она будет получена из исходных файлов на вашем компьютере.

## 2. Подготовка Windows

Распакуйте архив в удобную папку. Откройте папку `etl_goods`, внутри которой находится `etl.py`, и запустите в ней PowerShell: в адресной строке Проводника введите `powershell` и нажмите Enter.

Сначала проверьте установленные версии Python:

```powershell
py -0p
```

Следующие команды рассчитаны на установленный у вас Python 3.10. Если список показывает только Python 3.11, 3.12 или 3.13, замените `-3.10` в первой команде на нужную версию. Если Python или команда `py` не найдены, пришлите вывод — сначала разберемся с окружением.

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m pip show pandas openpyxl
```

Для установки библиотек нужен доступ в интернет. После установки проект работает локально. Активировать окружение и менять политику выполнения PowerShell не требуется: команды обращаются прямо к его интерпретатору. Microsoft Excel и отдельный сервер БД для запуска не нужны.

## 3. Первый запуск

```powershell
.\.venv\Scripts\python.exe -X utf8 etl.py
.\.venv\Scripts\python.exe -X utf8 show_results.py
```

Ожидаемые показатели для исходных файлов из архива:

| Показатель | Значение |
|---|---:|
| Прочитано поставщиков | 3 |
| Прочитано строк каталога | 13 |
| Прочитано строк остатков | 17 |
| Загружено поставщиков | 3 |
| Загружено уникальных товаров | 12 |
| Загружено строк остатков | 11 |
| Отклонено строк, включая дубли | 7 |
| Товаров в наличии | 9 |
| Товаров для пополнения | 7 |
| Суммарное пополнение, шт. | 18 |
| Товаров с неизвестным остатком | 1 |

Контроль количества строк: 33 прочитанные строки = 26 загруженных + 7 отклоненных. Проверка БД должна показать `Целостность БД: ok` и `Нарушения внешних ключей: 0`.

## 4. Просмотр четырех выборок

Все товары, включая товар без сведений об остатке:

```powershell
.\.venv\Scripts\python.exe -X utf8 show_results.py --view all
```

Товары в наличии:

```powershell
.\.venv\Scripts\python.exe -X utf8 show_results.py --view available
```

Товары для пополнения:

```powershell
.\.venv\Scripts\python.exe -X utf8 show_results.py --view restock
```

Товары поставщика S01:

```powershell
.\.venv\Scripts\python.exe -X utf8 show_results.py --view supplier --supplier S01
```

В последней выборке должны быть P001, P002, P003 и P011. Для другого поставщика замените S01 на S02 или S03. Эта команда только читает БД. Чтобы также сформировать CSV по другому поставщику, запустите `etl.py --supplier S02`.

## 5. Ошибки данных и повторная загрузка

Посмотрите строки, отклоненные при обработке:

```powershell
.\.venv\Scripts\python.exe -X utf8 show_results.py --view errors
```

В учебном наборе намеренно оставлены два точных дубля, отрицательное и дробное количество, пустое количество, неизвестный код товара и пустой код товара. Номер `row` соответствует строке исходного файла с учетом заголовка. Значения отклоненных записей находятся в `results/rejected.csv`.

Повторите загрузку и проверьте количество строк:

```powershell
.\.venv\Scripts\python.exe -X utf8 etl.py
.\.venv\Scripts\python.exe -X utf8 show_results.py
```

В БД по-прежнему должны быть 3 поставщика, 12 товаров и 11 строк остатков. Затем запустите проверки:

```powershell
.\.venv\Scripts\python.exe -X utf8 test_etl.py
```

Ожидаемый итог: `Ran 8 tests` и `OK`. Тесты используют временные копии файлов и не меняют ваши данные и рабочую БД.

Проверяется не только повторная загрузка, но и отсутствие подмены неизвестного остатка нулем, сохранность БД при отсутствии файла или неверной структуре, обновление количества после изменения источника, отклонение конфликтующих ключей и остановка при полностью непригодном наборе остатков.

## 6. Файлы результата

| Файл в `results` | Содержимое |
|---|---|
| `goods.db` | SQLite с таблицами `suppliers`, `products`, `inventory` |
| `all_goods.csv` | Полный каталог с поставщиком, остатком и статусом |
| `available.csv` | Товары с количеством больше нуля |
| `restock.csv` | Товары ниже минимального остатка и количество для пополнения |
| `by_supplier.csv` | Товары выбранного поставщика, по умолчанию S01 |
| `rejected.csv` | Отклоненные строки с причинами |
| `summary.json` | Счетчики загрузки и итоговых выборок |
| `run.log` | Журнал последнего запуска через `etl.py` |

CSV записываются в UTF-8 с BOM и разделителем-запятой. Если Excel показывает все в одном столбце, импортируйте файл через «Данные → Из текста/CSV» и выберите запятую. Для демонстрации достаточно `show_results.py`.
